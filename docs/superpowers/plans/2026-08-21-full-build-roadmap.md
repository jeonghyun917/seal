# 개인정보 전자동의·증적 관리시스템 전체 구축 로드맵

**구현 기준:** `docs/superpowers/specs/2026-08-21-consent-system-full-build-design.md`

## 목표

전자서명, SMS·알림톡, OTP, 본인확인, 추적 픽셀, 민감정보·고유식별정보, 만 14세 미만, SSO·LDAP, Redis·Kafka·유료 KMS를 제외하고 일반 개인정보 동의 업무의 전체 수명주기를 운영 가능한 수준으로 구축한다.

## 공통 완료 기준

- 각 기능은 DB 패치·검증 SQL, 도메인 규칙, MyBatis, Spring MVC/JSP, 권한·범위 검사, 감사 이벤트를 함께 구현한다.
- 도메인 및 보안 규칙은 실패 테스트를 먼저 작성하고 red-green-refactor 순서를 지킨다.
- 적용된 SQL은 수정하지 않고 `database/03_patch`에 누적한다.
- 각 단계 종료 때 전체 테스트, WAR 패키징, PostgreSQL 검증, `localhost:9090` 브라우저 스모크 테스트를 수행한다.
- 로컬 SMTP는 기본 비활성화한다. 승인된 수신자·발신자에 한해 25번 무인증 릴레이의 앱 Outbox 실발송을 1건 인수했고, 평상시에는 `SEAL_MAIL_ENABLED=false`를 유지한다.

## 단계

1. **관리자·정책 기반 완성**: 조직, 관리자, 역할·권한·범위, 보유정책, 처리업무, 감사조회.
2. **템플릿**: 구조화 동의 항목, 검토·승인·발행, 불변 버전, HTML 미리보기.
3. **대상자·요청**: 개별/Excel 반입, 마스킹, 요청 스냅샷, 만료·취소·링크 재발급.
4. **공개 동의**: 스캐너 안전 진입, 모바일 항목 결정, 확인·최종 제출, 중복 제출 차단.
5. **이메일**: 단일 스냅샷 HTML, 즉시·예약 발송, PostgreSQL Outbox, 재시도·재발송, 상태 검색.
6. **증적·권리·수명주기**: PDF/JSON/매니페스트/HMAC, 철회·권리요청, 보존 보류, 파기, 통계.
7. **통합 인수**: 로컬 보안·동시성·접근성·모바일·SMTP 인수와 운영 환경의 백업/복구·HTTPS·설치 검증.

각 단계는 독립 상세 계획과 검증 기록을 남긴다.
